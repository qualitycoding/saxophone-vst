# Deviations

| Step | Situation | Choice | Rationale |
|---|---|---|---|
| S-007 | D-008/D-009 specify a per-entry `tuning_scale`, but `ResonatorParams` (public header) had no field for it. | Added `double tuningScale = 1.0;` to `ResonatorParams` (additive; no existing signature changed; frozen tests unaffected). | Smallest reversible way to carry the calibrated scale from the table to the voice without baking it into poles (T-026 checks raw poles). |
| S-007 | Plan said "CMake custom command" to embed the table. | Embedding is done at configure time with `file(READ ... HEX)` + `file(CONFIGURE ...)` and `CMAKE_CONFIGURE_DEPENDS`. | Same result, fewer moving parts; a byte array avoids MSVC string-literal limits. |
| S-008 | The plugin must report the decimation-filter latency to the host, but `SaxVoice` had no accessor. | Added `int SaxVoice::latencySamples() const noexcept` (additive). | A-010 says "no added latency"; the linear-phase half-band cascade costs ~0.2 ms, which is reported honestly to the host rather than hidden. |
| S-008 | D-006 gave `tau_base = 15 ms` with attack delay `5 tau` (eq. 17), which makes a ~150 ms attack. | `tau_base = 5 ms`, delay `3 tau` (VoiceTuning.h; D-006 allows retuning). | Sax attacks are tens of ms; retuned further in S-016 if T-022b requires. |
| S-008 | The frozen `reedFlow()` uses `sign(d) (d^2+eta)^(1/4)`, which jumps by +-0.36 zeta at d=0. | The real-time voice uses the smooth form `d / (d^2+eta)^(1/4)` (identical to <1 % for |d| > 0.3); the reference integrator keeps the specified form. | The jump makes a relay-type chatter that never decays after note-off; the smooth law gives the strong reed-channel damping a real reed has. |
| S-008 | The simplified TMM leaves the first resonance too strong with the register vent open and gives peak2/peak1 up to 1.8 for the lowest unvented notes (1.33 in Colinot's measured D#). Result in the voice: all vented notes oscillate on the weakened first mode, notes 49-51 jump an octave. | `generate_table.py` post-fit corrections: vented entries' mode-1 residue x0.15; unvented entries' mode-1 residue raised so peak2/peak1 <= 1.15. Documented in the generator. | Found by probing the voice (pitch/regime per note). Pole frequencies (and so f2/f1, T-026) untouched. Same device as D-007 (explicit mode-1 attenuation). Enlarging the TMM hole radius was tried and does not work (it shortens the tube instead). |
| S-008 | Reed eigenfrequency 4224 rad/s (Table 1, D# fitting) is below most vented notes; they do not oscillate above ~600 Hz. | Voice uses `kReedOmega = 8448` rad/s (embouchure-adjusted). The reference integrator keeps Table 1. | Verified by probing: with 8448 all notes 49..81 speak in the correct register. Known residual: written 79/80 (concert 70/71) are marginal at velocity 0.3 (S-016 risk). |
| S-008 | The simplified TMM gives f2/f1 ~ 2.01 for the lowest notes and only a ~2x suppression of the first impedance peak by the register vent; both made the voice pick the wrong register (octave jumps on written 58/59; vented notes locked onto the weakened first mode). | `generate_table.py` post-fit calibration: vented entries get mode-1 residue x0.1; first-register entries with f2/f1 < 2.07 get Im(s2) raised to 2.07 Im(s1) (alto measured 2.078, Colinot 2021). | Matches measured alto behaviour; T-026 bounds (1.98..2.20) still hold. A larger hole radius was tried first and did not work uniformly across notes. |
| S-008 | D-006 overblow terms alone did not brighten the tone monotonically (T-013). | Added `kOverBrightDb = 12 dB` extra high-shelf gain at overblow = 1, and harmonic-mode mode-1 scale 0.3 -> 0.1 (D-007 starting values). | Both are VoiceTuning.h constants meant to be tuned. |
| S-009 | Harmonic mode (D-007) was 0..-88 cents off after first-register calibration; one global stretch cannot fix an irregular per-note pattern. | Added optional `harmonic_stretch` per table entry (additive field `ResonatorParams::harmonicStretch`, default 1.0, range [0.8, 1.25]); `Im(s2) = 2 * harmonicStretch * Im(s1)` in harmonic mode. `sax_calibrate` sets it by grid search at velocity 0.7 (accepts <= 40 cents; actual worst case 14 cents). | T-012 allows +-70 cents. Pitch-vs-stretch has a jump of ~70 cents for a few notes, so iteration is replaced by search. |
| S-009 | Table build is now two stages. | `tools/build_table.sh` = `generate_table.py` then `sax_calibrate`. Running the generator alone resets `tuning_scale`/`harmonic_stretch`. | Calibration needs the C++ voice. |
